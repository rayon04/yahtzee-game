# Yahtzee

5つのサイコロで役を作る、ダイスゲーム「ヤッツィー」です。
カレン・ヒナ・エレナの3人のキャラクターと、1対1で対戦します。

iPhoneのホーム画面に追加すると、アプリのように単独で起動でき、通信がなくても遊べます。

## 遊び方

1. サイコロを振ります（1ターンに最大3回）。
2. キープしたいサイコロをタップして、残りだけ振り直します。
3. 出た目で、13個の役のうち1つを選んで得点を記入します。
4. 13ターンで全部の役を埋めたとき、合計点が高いほうの勝ちです。

### 得点の早見表

| 役 | 得点 |
|---|---|
| エース〜シックス | その数字の目の合計 |
| 上段ボーナス | 上段の合計が63点以上で +35点 |
| スリーカード | 同じ目が3個以上で、5個の合計 |
| フォーカード | 同じ目が4個以上で、5個の合計 |
| フルハウス | 25点 |
| スモールストレート（4連続） | 30点 |
| ラージストレート（5連続） | 40点 |
| ヤッツィー（5個同じ） | 50点 |
| チャンス | 5個の合計 |

ヤッツィー欄に50点を記入したあと、もう一度ヤッツィーが出ると、100点のボーナスが入ります。

### モード

- **スタンダード**: キャラクターごとに決まった強さの相手と対戦します。
- **フリー**: キャラクターと強さを自由に選べます。「ランダム」を選ぶと、対戦のたびにおまかせで決まります。

### 戦績

最後まで遊んだ試合は、戦績に記録されます（プレイ回数、勝率、最高スコアなど）。
キャラクター別、強さ別にも見られます。「イカサマモード」を使った試合は、戦績に含まれません。

## iPhoneのホーム画面に追加する

1. **Safari** でこのページを開きます。
2. 共有ボタンを押して、「ホーム画面に追加」を選びます。
3. ホーム画面に追加されたアイコンから起動します。

はじめて開くときだけ、通信が必要です。2回目以降は、通信がなくても遊べます。

## 保存されるデータ

- 戦績と設定は、お使いの端末の中にだけ保存されます。外部には送信されません。
- Safariで遊んだデータと、ホーム画面のアプリで遊んだデータは、別々に保存されます。
- アプリのアイコンを削除したり、ブラウザのデータを消去したりすると、保存したデータも消えます。

## 更新

通信できる状態でアプリを開くと、新しい版を自動で取得します。アプリを一度終了して開き直すと、新しい版になります。
戦績と設定は、更新しても消えません。

## 動作環境

- iOS 15.4以降のiPhoneを推奨します。
- 画面は縦向き専用です。横向きにすると表示が崩れます。

## プライバシー

アカウント登録は不要です。広告、アクセス解析、外部サービスへの通信はありません。
