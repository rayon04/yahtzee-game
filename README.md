# Yahtzee（PWA版）

iPhoneのホーム画面から単独起動できる、完全オフライン対応のアプリ版です。
ゲームの内容・見た目・機能は Artifacts 版と同一です（コードは変更していません）。

## ファイル構成

```
index.html        ゲーム本体（画像もすべて内蔵）
manifest.json     アプリ情報（名前・アイコン・縦画面・単独起動）
sw.js             Service Worker（オフライン用キャッシュと自動更新）
icons/            アプリアイコン（180 / 192 / 512 / マスク用512 / favicon）
.nojekyll         GitHub Pages用（そのまま置く）
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例: `yahtzee`、Public）。
2. このフォルダの中身をすべて、リポジトリの一番上の階層にアップロードする。
   - 「Add file」→「Upload files」に、`index.html` `manifest.json` `sw.js` `.nojekyll` `icons` フォルダをドラッグ。
   - `.nojekyll` は先頭が「.」のため見えにくいので、含め忘れないこと。
3. 「Settings」→「Pages」→ Source を **Deploy from a branch**、Branch を **main** / **/(root)** にして Save。
4. 1〜2分待つと `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開される。

## iPhone に入れる

1. **Safari** で上の URL を開く（他のブラウザではホーム画面アプリにならない）。
2. 共有ボタン →「ホーム画面に追加」→「追加」。
3. ホーム画面のアイコンから起動する。アドレスバーのない独立したアプリとして開く。
4. **ホーム画面から起動したアプリの保存領域は、Safari とは別です。** 戦績や設定は、ホーム画面のアプリ側で遊んだ分だけが記録されます。

## オフラインで動くことの確認（初回は必ず）

1. 通信できる状態でホーム画面のアイコンから起動し、タイトル画面が出るまで待つ。
2. アプリを完全に終了する（画面下から上にスワイプして消す）。
3. 機内モードをオンにする。
4. もう一度アイコンから起動し、次を確認する。
   - タイトル、モード選択、キャラ選択、VS演出、対戦、戦績、設定が開く
   - 画像（キャラ、背景、ロゴ）がすべて表示される
   - 対戦を最後まで遊べ、戦績が記録される

## アップデート手順

1. Claude に「PWA版も更新して」と頼み、新しい ZIP を受け取る。
2. GitHub のリポジトリで、`index.html` と `sw.js`（必要なら `icons` も）を **同じ名前で上書き** アップロードして Commit する。
   - `sw.js` の中の `VERSION` の日付が新しくなっていれば OK（Claude が更新して渡す）。
3. 1〜2分で公開される。
4. iPhone でアプリを **通信できる状態で起動** する。新しい版は裏で自動的にダウンロードされる。
5. アプリを一度終了して、もう一度起動すると新しい版になる（反映されないときは、もう一度繰り返す）。

保存データ（戦績・設定）は、更新しても消えません。

## 注意

- 動作の目安は iOS 15.4 以降です。
- 画面は縦向き用です（iPhone は向きの固定ができないため、横向きにすると表示が崩れます）。
- アプリのアイコンを削除すると、そのアプリの保存データ（戦績・設定）も消えます。
- ステータスバーは黒（白文字）で固定しています。明るい画面でも文字が読めるようにするためです。
- Artifacts 版の戦績・設定は、PWA 版には引き継がれません（保存場所が別のため）。
